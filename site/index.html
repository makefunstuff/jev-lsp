jev-lsp

WIP

LSP server for Jev rules. Pattern → typed decide on that line → normal diagnostics / code actions / code lens. Not chat.

What you can do

  • Match lines (regex or other inspection)
  • Ask one typed question per hit
  • Surface findings when p clears the floor
  • Run the same rules with jev (CLI / CI)
  • Use hosted Jev or another decide endpoint

Setup

  1. Install (Rust ≥ 1.75): 
    cargo install --git https://github.com/makefunstuff/jev-lsp --locked jev-lsp jev
  2. Key: 
    export TYPESAFE_API_KEY=…
  3. Neovim ≥ 0.12 (nvim/ in the repo): 
    ln -s /path/to/jev-lsp/nvim ~/.local/share/nvim/site/pack/jev/start/jev
require('jev').setup({})
    Open a file. :checkhealth jev. Save.

Other editors: start jev-lsp as a normal language server.

OpenCode: use editors/opencode/ (native path flakes). Bridge remaps Warning→Error with a [jev warning] prefix; set JEV_OPENCODE_REMAP=0 to opt out.

Rule example

.jev/rules/no-unwrap-in-handlers.json

{
  "schema": "jev.rules/1",
  "rules": [
    {
      "id": "no-unwrap-in-handlers",
      "title": "Unwrap in a request handler",
      "text": "A handler must not unwrap: a bad request would take the worker down. Return the error instead.",
      "severity": "warning",
      "applies_to": ["**/src/**/*.rs"],
      "inspection": {
        "kind": "regex",
        "pattern": "\\.unwrap\\(\\)"
      },
      "judgement": {
        "question": "Is this unwrap in request-handling code that can fail on bad input?",
        "criteria": {
          "true": "ships in a handler / request path and the value is not proven safe",
          "false": "tests, docs, or an invariant on the surrounding lines covers it"
        },
        "min_probability": 0.85
      },
      "verb_hint": "fix"
    }
  ]
}

No pattern match → no decide call.
