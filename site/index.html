jev-lsp

Language server. Not a product.

Runs Jev classifier rules (.jev/rules/*.json) as ordinary LSP diagnostics, code actions, and code lens. One line → one typed answer + probability. Not chat.

WIP. Interface and config may change.

Install

cargo install --git https://github.com/makefunstuff/jev-lsp --locked jev-lsp jev

Neovim

ln -s /path/to/jev-lsp/nvim ~/.local/share/nvim/site/pack/jev/start/jev
require('jev').setup({})

Export a decide API key, open a buffer, save.
